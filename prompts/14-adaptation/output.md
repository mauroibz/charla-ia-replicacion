1. **Extraction & sequencing.** DNA extraction with a kit validated for humic-acid-heavy soils (e.g. bead-beating + PCR-inhibitor removal step), amplify V3-V4 or V4 16S region, sequence on Illumina (2x250 or 2x300).
2. **Raw read QC.** Quality-filter and trim primers (cutadapt), inspect quality profiles per run before choosing DADA2 truncation lengths.
3. **Denoising to ASVs.** Run DADA2 (or Deblur) inside QIIME2, per-run error learning, produce the ASV feature table + representative sequences.
4. **Taxonomic classification.** Classify ASVs against SILVA (or a soil-specific curated subset if available); expect a higher proportion of unclassified/novel taxa than a human-sample project would see — don't treat that as a pipeline failure.
5. **Sanity-check richness range against the paper's synthetic validation.** Before trusting the four-category metric framework as-is, compare your observed ASV counts per sample to the 50-500 feature range the paper's synthetic datasets covered. If soil samples exceed that range substantially, note it as a caveat rather than assuming full transferability.
6. **Compute the four core metrics per sample:** Observed features (richness), Berger-Parker (dominance), Faith's PD (phylogenetics, needs a rooted tree — build via QIIME2's phylogeny pipeline), Shannon entropy (information).
7. **Check metric correlation on your own data** rather than assuming the paper's stool-derived redundancy claim — compute pairwise correlations across your 24 samples before deciding whether reporting all four is redundant or actually necessary here.
8. **Group comparison (tilled vs. no-till).** Kruskal-Wallis per metric between groups; if you want a formal significance claim, decide *before* running the test which single metric is your primary outcome, so trying all four until one is significant doesn't become an implicit multiple-comparisons problem.
9. **Beta diversity as a complement.** Weighted/unweighted UniFrac + PERMANOVA to check whether community composition (not just diversity) differs by tillage.
10. **Report.** State denoising method + version, reference database + version, exact metric formulas used, and — given the correlation-check in step 7 — justify which metrics you're reporting rather than defaulting to "the paper's four."
